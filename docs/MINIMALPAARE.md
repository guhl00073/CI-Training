# Minimalpaar-Katalog – Phonetische Kategorien

Der Minimalpaar-Katalog umfasst **109 Übungsgruppen** zur auditiven Laut- und Vokaldifferenzierung für das Cochlea-Implantat Hörtraining.

---

## 🎯 Abgedeckte Phonetische Kontraste

### 1. Plosive (Verschlusslaute stimmlos vs. stimmhaft)
- **P vs. B:** *Pass / Bass*, *Packen / Backen*, *Pein / Bein*, *Pille / Bille*
- **T vs. D:** *Tasse / Dasse*, *Teich / Deich*, *Tore / Dore*, *Tante / Dante*
- **K vs. G:** *Kamm / Gramm*, *Karten / Garten*, *Kasse / Gasse*, *Kuhl / Gul*

### 2. Frikative & Reibelaute
- **F vs. W:** *Fee / Weh*, *fiel / viel*, *fest / West*, *Fisch / Wisch*, *Feld / Welt*
- **W vs. B:** *Welle / Bälle*, *wach / Bach*, *Wand / Band*, *Wein / Bein*, *wild / Bild*
- **F vs. S:** *Fee / See*, *Fahne / Sahne*, *Affe / Asse*, *Fink / Zink*
- **S vs. SCH:** *Saal / Schal*, *Sonne / Schonung*, *Sägen / Schämen*, *Kasse / Kasche*
- **CH vs. SCH (Ich-Laut /ç/ vs. /ʃ/):** *Kirche / Kirsche*, *Dich / Fisch*
- **CH vs. K (Ach-Laut /x/ vs. Plosiv K):** *Dach / Dank*, *Buch / Bock*, *lachen / Lacken*
- **R vs. H:** *Rad / Had*, *Rot / Hut*, *Rose / Hose*, *Rasse / Hasse*

### 3. Affrikaten & Zischlaute
- **S vs. Z (/ts/):** *Kasse / Katze*, *Tasse / Tatze*, *Seile / Zeile*, *Siel / Ziel*

### 4. Nasale (Nasenlaute)
- **M vs. N:** *Maus / Naus*, *Mutter / Nutter*, *Mund / Nund*, *Leim / Lein*
- **N vs. NG:** *Wanne / Wange*, *Hennen / hängen*, *Rinne / Ringe*, *Sinn / Singen*

### 5. Liquidae & Schwinglaute
- **R vs. L:** *Rolle / Lolle*, *Ratten / Latten*, *Robe / Lobe*, *Ries / Lies*

### 6. Vokallänge (Kurz- vs. Langvokale)
- *Bahn / Bann*, *Miete / Mitte*, *Wal / Wall*, *Besen / besser*, *viel / Film*, *Haken / Hacken*, *Nase / nasse*, *Hüte / Hütte*, *Robe / Robbe*, *Schal / Schall*, *Aal / All*, *Ofen / offen*

### 7. Reim-Gruppen (Mehrfachauswahl)
- **-ut:** *Mut, Glut, Flut, Gut, Hut, Wut*
- **-ein:** *Bein, Pein, Stein, Wein, Fein*
- **-anne:** *Kanne, Panne, Tanne, Wanne*
- **-and:** *Hand, Wand, Band, Land, Sand, Pfand*
- **-ock:** *Bock, Dock, Lock, Rock, Socken*
- **-aus:** *Haus, Maus, Raus, Laus, Strauß*
- **-ing:** *Ring, Ding, Sing, King*
- **-ecke:** *Ecke, Decke, Hecke, Schnecke, Stecke*
- **-atz:** *Satz, Katz, Platz, Schatz, Fratz*
- **-iege:** *Wiege, Liege, Ziege, Fliege*
- **-ern:** *Stern, Kern, Gern, Lern*
